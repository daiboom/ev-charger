# EV Charger

전기차 충전기 키오스크의 데스크톱 시뮬레이터입니다. 이 프로세스가 충전 세션과 컨택터 명령을 담당하지만, 저장소에 포함된 충전기는 시뮬레이터뿐입니다. 실제 전력 출력, 결제 단말기, 운영 서버에는 연결하지 않습니다.

인증된 충전기가 아니고 IEC 61851 구현이 아닙니다.

## 실행

Rust stable이 필요합니다.

```bash
cargo run
```

전체화면:

```bash
cargo run -- --fullscreen
```

창 크기의 기본값은 800×600입니다. 이미지는 없어도 됩니다. `assets/images/splash_bg.jpg`가 있으면 스플래시 배경으로 씁니다.

로그는 `RUST_LOG`로 조절합니다. 기본값은 `info`입니다.

## 화면 흐름

1. 에너지(kWh), 목표 전지 잔량(%), 풀충전 중 하나를 고르고 급속·일반·저속 전력 상한을 고릅니다.
2. 차량 연결을 기다립니다. 장비가 없으면 화면의 시뮬레이터 버튼으로 케이블 연결과 차량 준비를 누릅니다.
3. 결제 수단을 고르면 시뮬레이터가 잠시 후 승인합니다. 승인 전에는 컨택터가 닫히지 않습니다.
4. 계량된 에너지로 요금이 계산됩니다. 중지, 목표 도달, 고장, 충전 중 분리는 컨택터를 엽니다.
5. 프로세스를 다시 시작해도 진행 중이던 충전은 복구하지 않습니다. 컨택터 명령은 열림에서 시작합니다.

기본 시뮬레이터 값은 명판이 아닙니다.

- 전력 상한: 급속 50 kW, 일반 7 kW, 저속 3 kW
- 시간 배율: 60배. 화면 상단에 `SIMULATOR 60x`로 표시됩니다.
- 요금: 공급된 에너지 1 kWh당 300 KRW

## 테스트

```bash
cargo test
```

세션 인터록, 목표 정지, 고장, 재시작 미복구를 디스플레이 없이 검사합니다.
